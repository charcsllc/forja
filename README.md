# lovable-alternative

An open alternative to Lovable — an AI-powered app builder that turns natural-language prompts into working, deployable web applications.

## Status

🚧 Early stage. Scaffolding in progress.

## Goals

- Prompt-to-app generation with a live preview
- Full source-code ownership (export / GitHub sync, no lock-in)
- Integrated database, auth, and one-click deploy
- Self-hostable
